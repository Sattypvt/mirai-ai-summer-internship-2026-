# 🎭 Multi-Modal Visual Novel Engine

An interactive, AI-powered Choose Your Own Adventure visual novel engine built with Python and Streamlit.

## 🌟 Features
- 🤖 **Dynamic Narrative:** Powered by Google's Gemini models for rich storytelling and dynamic branching choices.
- 🎨 **AI Image Generation:** Dynamically creates scene visuals via Pollinations AI.
- 🎙️ **Audio Narration:** Text-to-speech integration with `gTTS`.
